# Database Schema v2 — Full Re-architecture

## Overview

Clean re-architecture of the database to match the agentic prototyping studio direction. Drops TUI, upstream OpenCode compatibility, workspace/console/share systems. Designed from the spec, not evolved from the old schema.

**Branch:** `opendesign-v2`
**Data loss:** Accepted (nothing worth preserving).
**Migration strategy:** Drop all tables, create new ones. No migration scripts.

---

## New Schema (13 tables)

### Naming Conventions
- Table names: `PascalCase` (Drizzle convention from existing codebase)
- Column names: `snake_case` (existing convention)
- JSON columns: `text({ mode: "json" }).$type<T>()`
- Timestamps: Spread `...Timestamps` (time_created, time_updated)
- Foreign keys: Always `onDelete: "cascade"`
- IDs: Text, generated via existing `Identifier` utility

### 1. ProductTable (replaces ProjectTable)

```typescript
// packages/opencode/src/product/product.sql.ts
import { sqliteTable, text, integer } from "drizzle-orm/sqlite-core"
import { Timestamps } from "../storage/schema.sql"

export const ProductTable = sqliteTable("product", {
  id: text().primaryKey(),           // git root commit hash (same as old project_id)

  directory: text().notNull(),       // absolute path to mono repo root

})
```

**Changes from ProjectTable:**
- Renamed `project` → `product`
- Dropped: `worktree`, `vcs`, `icon_url`, `icon_color`, `time_initialized`, `sandboxes`, `commands`
- Added: `name`, `directory`, `git_root`
- `id` generation stays the same (git root commit hash)

### 6. AgentTable (replaces SessionTable)

```typescript
// packages/opencode/src/agent/agent.sql.ts
import { sqliteTable, text, integer, index } from "drizzle-orm/sqlite-core"
import { FeatureTable } from "../feature/feature.sql"
import { AnnotationTable } from "../annotation/annotation.sql"
import { Timestamps } from "../storage/schema.sql"
import type { PermissionNext } from "../permission/next"

export const AgentTable = sqliteTable("agent", {
  id: text().primaryKey(),
  feature_id: text().notNull().references(() => FeatureTable.id, { onDelete: "cascade" }),
  annotation_id: text().references(() => AnnotationTable.id, { onDelete: "set null" }),
  branch: text(),                     // git branch: agent/{slug}
  status: text().notNull().$type<"working" | "waiting" | "done" | "error">().default("working"),
  color: text(),                      // hex color for canvas display
  title: text().notNull(),
  directory: text().notNull(),        // working directory
  version: text().notNull(),
  permission: text({ mode: "json" }).$type<PermissionNext.Ruleset>(),
  ...Timestamps,
}, (table) => [
  index("agent_feature_idx").on(table.feature_id),
  index("agent_annotation_idx").on(table.annotation_id),
])
```

**Changes from SessionTable:**
- Renamed `session` → `agent`
- Dropped: `project_id` (scoped through feature→product), `workspace_id`, `parent_id`, `slug`, `share_url`, `summary_*`, `revert`, `time_compacting`, `time_archived`
- Added: `feature_id`, `annotation_id`, `branch`, `status`, `color`
- Kept: `title`, `directory`, `version`, `permission`, `Timestamps`
