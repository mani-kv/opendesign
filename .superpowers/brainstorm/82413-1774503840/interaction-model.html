Interaction Rules

Component Detection
  • Figma MCP returns full node tree with component metadata
  • Each component instance → invisible hit region on canvas
  • Nested components: deepest match wins on hover
  • Scroll up tree: hold Alt to select parent component
Selection & Annotation
  • Click: select component, show annotation anchor
  • Shift+click: multi-select for grouped annotation
  • Right-click: context menu (Explore, Annotate, Info)
  • Annotation popup: prompt input + agent tag + variation count + DS slider
Design System Slider
  • Left: strict DS — agent uses only existing components & tokens
  • Right: creative — agent can propose new patterns, layouts, styles
  • Middle: agent prefers DS but can deviate with justification
  • Persists per annotation (different sections can have different settings)
Agent Sidebar
  • Each annotation spawns an agent with its own chat thread
  • Sidebar shows all active agents, click to open chat
  • Agent chat is secondary — canvas annotation is primary interaction
  • Chat useful for follow-up refinement after initial exploration
