Key Behaviors

Approval
  • Approve variation → code swaps in live Sandpack prototype
  • Auto-checkpoint with descriptive label
  • Unapproved variations dim (30% opacity) but persist
  • Click dimmed variation to restore or re-explore from it
Checkpoints
  • Stored as Sandpack file snapshots (lightweight)
  • Timeline UI at bottom of canvas or in sidebar
  • Restore: reverts prototype to that checkpoint's code
  • Fork: creates a new exploration branch from any checkpoint
  • Compare: side-by-side diff between any two checkpoints
Multiple Agents
  • Each agent works on a different section independently
  • Approving one agent's work doesn't affect others
  • Agents can see the current prototype state (after approvals)
  • Color-coded per agent (indigo, amber, etc.)
Enrichment
  • Add personas, data, scenarios to annotation prompts
  • AI-recommended enrichments based on component type
  • States: empty, loading, error, success, edge cases
  • Modes: light/dark, compact/comfortable, mobile/desktop
